# 🍽️ Smart Mess Food Analytics System

## 📌 Overview

This project is an interactive web-based analytics dashboard built using Python and Streamlit to analyze mess food quality.

It transforms raw mess menu and feedback data into meaningful insights, helping identify patterns across meals, days, and food categories.

---

## 🚀 Features

* 📊 Interactive dashboard with filters (Day, Meal, Category)
* 📈 Advanced visualizations using Plotly
* 🏆 Best & Worst food identification
* 🤖 Food recommendation system
* 📊 Consistency analysis of food ratings
* 🚨 Alert system for low-performing dishes
* 🔮 Rating prediction feature
* 🧠 Smart insights generation
* 📊 Food quality scoring system
* 🔄 Data pipeline representation

---

## 🧠 Data Pipeline

1. Data Collection → Mess menu + simulated feedback
2. Data Processing → Cleaning & structuring using Pandas
3. Analysis → Pattern detection & aggregation
4. Visualization → Interactive dashboard
5. Insights → Recommendations & alerts

This mimics real-world data pipelines used in AI/LLM systems.

---

## 📊 Key Insights

* Hygiene is the lowest rated factor
* Dinner meals tend to underperform
* Certain dishes consistently receive lower ratings
* Food quality varies across days
